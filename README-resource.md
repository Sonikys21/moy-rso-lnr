# Мой РСО · ЛНР

Цифровой прототип маршрута «интерес → проба → обучение → отряд → отзыв → следующий карьерный шаг», созданный по разделу 7.1 рабочей тетради Луганского регионального отделения РСО. Оформление основано на предоставленном логотипе `Лого реготделения.png` и фирменной цифровой палитре из `брендбук.pdf`: голубой `#13c4e8`, белый `#ffffff`, светло-серый `#eeeeee`, чёрный `#000000`.

## Открыть

Откройте **`app.html`** в браузере — это самостоятельный файл со встроенными стилями, скриптом и логотипом. Его можно переслать отдельно от папки. Внешняя ссылка на официальный личный кабинет РСО требует доступа к интернету. Сборка и установка зависимостей для просмотра не требуются.

Если меняете исходные `app.template.html`, `app.css`, `app.js` или `Лого реготделения.png`, пересоберите единый файл командой `node build-standalone-app.cjs`.

## Что работает

- Навигатор по возрасту и интересу, разбор учебного кейса без рейтинга.
- Справочник направлений, фильтрация, место для проверенных региональных точек.
- Личный маршрут и локальный черновик запроса со скачиванием файла.
- Локальное портфолио действий и результатов, экспорт черновика резюме.
- Демонстрационная панель куратора с локальными черновиками и перечнем контрольных точек.
- Адаптивный интерфейс для телефона и компьютера.

## Что требуется для реального запуска

Массив `verifiedPoints` в `app.js` намеренно пуст: площадки, адреса, квоты и контакты публикуются только после проверки региональным отделением и согласования с партнёрами. Черновики и отмеченные шаги сохраняются **только в браузере пользователя** через `localStorage`; отправки куратору, подтверждения этапов, учётной записи и серверного хранения сейчас нет. Не используйте демонстрационную страницу куратора как настоящий приём заявок.

Для следующей версии нужны утверждённый реестр возможностей с датами актуальности, защищённый серверный приём заявок, роли доступа, подтверждение возраста/согласий и рабочего допуска, журнал ответа куратора, интеграция с официальной платформой РСО и согласованный порядок обработки данных. Не добавляйте персональные данные в код или статические файлы.
