# Мой РСО · ЛНР

Прототип цифрового маршрута для знакомства с направлениями Российских студенческих отрядов в Луганской Народной Республике.

Откройте [приложение](app.html) локально в браузере: `app.html` — автономный файл со встроенными стилями, скриптами и логотипом. Онлайн-версия прототипа: [Мой РСО · ЛНР](https://rso-lugansk-guide-ekaaqlw4c-sonikys21.vercel.app).

## Возможности

- Навигатор направлений по возрасту и интересу.
- Справочник направлений и место для проверенных региональных площадок.
- Личный маршрут с отметками шагов.
- Черновик запроса, примеры навыков и экспорт черновика резюме.

Данные маршрута и черновики хранятся только в браузере через `localStorage`. Сейчас нет приёма заявок, личных учётных записей и подтверждения участия; действующие площадки публикуются только после проверки и согласования. Участие в реальных программах уточняется через официальные каналы РСО.

## Разработка

Редактируйте `app.template.html`, `app.css` и `app.js`. Для обновления автономного `app.html` запустите:

```sh
node build-standalone-app.cjs
```

Дополнительные сведения — в [описании ресурса](README-resource.md).
